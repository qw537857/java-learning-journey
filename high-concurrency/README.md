> 搜索引擎扛检索、Redis 扛热点计数、JWT 扛无状态认证。

## 为什么这三件套总是一起出现?

- **全文检索**:MySQL 的 `LIKE '%关键词%'` 不走索引、不能分词、不能算相关度,搜索体验差 → 上 Elasticsearch。
- **高并发统计**:浏览量、点赞这种"只加不减"的热点数据,直接 UPDATE 数据库会打爆行锁 → 先写 Redis,再定时落库。
- **JWT 认证**:微服务多实例部署,Session 不共享 → 用无状态 Token,谁都能验签,不用存服务器。
