## 一、多模态是什么

**多模态 = 不同类型的数据输入**:文本、图像、声音、视频。

之前我们只做文本对话,因为选的模型(deepseek、qwen-max)是**纯文本模型**。想支持其它模态,要换模型:

- Ollama:搜索时点 **vision**,能找到支持图像识别的模型;
- 阿里云百炼:**qwen-omni** 系列是文本、图像、音频、视频全模态(还支持语音合成),非常强。

> ⚠️ **兼容性坑**:当前 SpringAI 版本对 qwen-omni 的支持不完整——**只支持文本和图片**,音频会报数据格式错误,视频完全不支持。
> 两个解决方向:① 换用 `spring-ai-alibaba`;② 自己重写 OpenAI 模型实现。

下面我们给入门时的对话机器人加上"图片识别"能力。

### 1.1 切换模型

其它业务还在用 qwen-max,所以**用 defaultOptions 单独给这个 ChatClient 指定模型**:

```java
@Bean
public ChatClient chatClient(OpenAiChatModel model, ChatMemory chatMemory) {
    return ChatClient.builder(model)
            .defaultOptions(ChatOptions.builder().model("qwen3.5-omni-flash").build())   // 多模态模型
            .defaultSystem("你是一位友好的智能助手,名字叫小助手,请耐心解答用户的问题。")
            .defaultAdvisors(
                    new SimpleLoggerAdvisor(),
                    MessageChatMemoryAdvisor.builder(chatMemory).build())
            .build();
}
```

## 二、多模态对话接口

要点:接口接收 `List<MultipartFile>`,把文件转成 SpringAI 的 **`Media`**,用 `.media(...)` 一起发出去。

```java
@RequestMapping(value = "/chat", produces = "text/html;charset=utf-8")
public Flux<String> chat(@RequestParam("prompt") String prompt,
                         @RequestParam("chatId") String chatId,
                         @RequestParam(value = "files", required = false) List<MultipartFile> files) {
    chatHistoryRepository.save("chat", chatId);

    if (files == null || files.isEmpty()) {
        return textChat(prompt, chatId);          // 纯文本
    }
    return multiModalChat(prompt, chatId, files); // 带附件
}

private Flux<String> multiModalChat(String prompt, String chatId, List<MultipartFile> files) {
    // 1. 把上传的文件解析为 Media 数组
    Media[] medias = files.stream()
            .map(file -> new Media(MediaType.valueOf(Objects.requireNonNull(file.getContentType())),
                                   file.getResource()))
            .toList().toArray(Media[]::new);

    // 2. 文本 + 媒体一起发送
    return multiChatClient.prompt()
            .user(p -> p.text(prompt).media(medias))
            .advisors(p -> p.param(ChatMemory.CONVERSATION_ID, chatId))
            .stream()
            .content();
}

private Flux<String> textChat(String prompt, String chatId) {
    return chatClient.prompt()
            .user(prompt)
            .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, chatId))
            .stream()
            .content();
}
```

启动后进入《AI 聊天》页面,即可上传图片让 AI 识别。

## 三、拓展一:会话记忆持久化(选学)

当前 `InMemoryChatMemory` 重启即丢。持久化有三条路:

1. 仍用 InMemoryChatMemory,但**停机时/定时**持久化到磁盘;
2. **自定义基于 Redis 的 ChatMemory**;
3. 直接换支持持久化的实现。

### 3.1 先解决一个前提:Message 不可序列化

SpringAI 的 `Message` 未实现 `Serializable`、也没有 public 构造方法 → **自己定义一个可序列化的 Msg**:

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class Msg {
    MessageType messageType;
    String text;
    Map<String, Object> metadata;

    public Msg(Message message) {                          // Message → Msg
        this.messageType = message.getMessageType();
        this.text = message.getText();
        this.metadata = message.getMetadata();
    }

    public Message toMessage() {                           // Msg → Message
        return switch (messageType) {
            case USER -> new UserMessage(text);
            case ASSISTANT -> new AssistantMessage(text, metadata);
            case SYSTEM -> new SystemMessage(text);
            default -> throw new IllegalArgumentException("Unsupported: " + messageType);
        };
    }
}
```

### 3.2 方案一:本地文件持久化

用 Spring 生命周期方法:`@PostConstruct` 启动时加载(`chat-history.json` + `chat-memory.json`),`@PreDestroy` 停机时写出:

```java
@PostConstruct
private void init() {
    // 读取 chat-history.json(会话历史)与 chat-memory.json(会话记忆)
    // 会话记忆通过 Msg.toMessage() 转回 SpringAI 的 Message 再 add 进 ChatMemory
}

@PreDestroy
private void persistent() {
    // 用 Jackson 把 chatHistory、ChatMemory 内部数据写成 JSON 文件
}
```

> 取 InMemoryChatMemory 内部数据要用**反射**读它的 `conversationHistory` 字段(之所以要自己造 Msg,就是为了能序列化)。

### 3.3 方案二:Redis 持久化

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      database: 0
```

```java
@RequiredArgsConstructor
@Component
public class RedisChatMemory implements ChatMemory {
    private final StringRedisTemplate redisTemplate;
    private final ObjectMapper objectMapper;
    private static final String PREFIX = "chat:";

    @Override
    public void add(String conversationId, List<Message> messages) {
        if (messages == null || messages.isEmpty()) return;
        List<String> list = messages.stream().map(Msg::new)
                .map(msg -> { try { return objectMapper.writeValueAsString(msg); }
                              catch (JsonProcessingException e) { throw new RuntimeException(e); } })
                .toList();
        redisTemplate.opsForList().rightPushAll(PREFIX + conversationId, list);
    }

    @Override
    public List<Message> get(String conversationId) {
        List<String> list = redisTemplate.opsForList().range(PREFIX + conversationId, 0, -1);
        if (list == null || list.isEmpty()) return List.of();
        return list.stream().map(s -> { try { return objectMapper.readValue(s, Msg.class); }
                                        catch (JsonProcessingException e) { throw new RuntimeException(e); } })
                .map(Msg::toMessage).toList();
    }

    @Override
    public void clear(String conversationId) {
        redisTemplate.delete(PREFIX + conversationId);
    }
}
```

会话历史同样可以用 Redis 的 **Set** 存:

```java
@Component
@RequiredArgsConstructor
public class RedisChatHistory implements ChatHistoryRepository {
    private final StringRedisTemplate redisTemplate;
    private static final String PREFIX = "chat:history:";

    public void save(String type, String chatId) { redisTemplate.opsForSet().add(PREFIX + type, chatId); }

    public List<String> getChatIds(String type) {
        Set<String> ids = redisTemplate.opsForSet().members(PREFIX + type);
        return ids == null || ids.isEmpty() ? Collections.emptyList()
                : ids.stream().sorted(String::compareTo).toList();
    }
}
```

> ⚠️ 注意:切到 Redis 方案后,要把内存实现(ChatMemory / ChatHistoryRepository)从 Spring 容器移除,避免冲突;
> Redis Set 无序,**要保证 chatId 单调递增**。

## 四、拓展二:持久化 VectorStore(选学)

生产上不用 SimpleVectorStore,换成真正的向量库。以 **RedisVectorStore** 为例(需要 Redis Stack):

```bash
docker run -d --name redis-stack -p 6379:6379 -p 8001:8001 redis/redis-stack:latest
# 命令行访问:docker exec -it redis-stack redis-cli
# 控制台:http://localhost:8001
```

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-vector-store-redis</artifactId>
</dependency>
```

```yaml
spring:
  ai:
    vectorstore:
      redis:
        index-name: spring_ai_index
        initialize-schema: true      # 自动初始化索引结构
        prefix: "doc:"
        distance-type: COSINE
  data:
    redis:
      host: your-redis-host
      port: 6379
      database: 0
```

配置好**无需声明 Bean**,可直接注入 `VectorStore` 使用。

### 4.1 踩坑记录(实战必看)

| 问题 | 解决 |
|------|------|
| 启动报错(连接/序列化) | 排除 lettuce,改用手动引入 **Jedis** |
| 容器里有两个 EmbeddingModel 冲突 | 给目标实现加 `@Primary` |
| `vectorStore.add()` 一次最多 10 条 | **分批写入**(每批 10 条) |
| 元数据过滤异常 | 去掉 `FILTER_EXPRESSION`(该版本 metafield 过滤有 bug) |
| 下载接口 NPE | 先判断 `resource == null || !resource.exists()` |

分批写入示例:

```java
public static <T> List<List<T>> splitBatch(List<T> list, int batchSize) {
    List<List<T>> batches = new ArrayList<>();
    for (int i = 0; i < list.size(); i += batchSize) {
        batches.add(list.subList(i, Math.min(i + batchSize, list.size())));
    }
    return batches;
}

// 原:vectorStore.add(documents);  // 最多 10 个
for (List<Document> batch : splitBatch(documents, 10)) {
    vectorStore.add(batch);
}
```

## 五、本节速记

1. 多模态 = 文本外的图片/音频/视频输入;换支持 vision/omni 的模型即可;
2. qwen-omni 与 SpringAI 当前版本**只兼容文本+图片**;音频/视频需换 spring-ai-alibaba 或自己实现;
3. 多模态接口:`Media[]` + `.user(p -> p.text(prompt).media(medias))`;
4. 会话记忆持久化:先造可序列化 `Msg`,再选本地文件(生命周期方法)或 Redis(List/Set);
5. 向量库换 Redis Stack 时注意:Jedis、@Primary、分批 add(10 条)、过滤 bug。
