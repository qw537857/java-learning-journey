## 一句话速记

1. 六种架构:增强 → 链式 → 路由 → 并行 → 协调器 → 评估优化,按业务复杂度选;
2. 路由模式 = **意图识别 + 分派**,适合业务分支独立;
3. 工程骨架:`AgentTypeEnum` + `Agent` 接口 + `AbstractAgent`(通用逻辑沉淀,子类只覆盖差异);
4. 智能体差异只有三处:**systemMessage() / tools() / advisors()**;
5. 提示词放配置中心热更新;内部意图标记要清理,别混进会话历史。
