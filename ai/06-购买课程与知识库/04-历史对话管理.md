## 一、异步设置标题

### 1.1 问题

- 新建会话时**没有标题**;
- 标题应该是**用户第一次提问的内容**(或 AI 提炼的短标题);
- `update_time` 每次提问都要更新。

### 1.2 实现:@Async 异步更新

```java
/**
 * 更新会话:标题为空则设置标题;每次都刷新更新时间
 */
@Async                                  // ★ 异步:不阻塞 AI 对话主流程
@Override
public void update(String sessionId, String title, Long userId) {
    ChatSession session = lambdaQuery()
            .eq(ChatSession::getSessionId, sessionId)
            .eq(ChatSession::getUserId, userId)
            .one();
    if (session == null) return;

    // 只在"标题为空 + 有新内容"时设置标题
    if (StrUtil.isEmpty(session.getTitle()) && StrUtil.isNotEmpty(title)) {
        session.setTitle(StrUtil.sub(title, 0, 30));       // 截前 30 个字
    }
    session.setUpdateTime(LocalDateTimeUtil.now());        // 每次提问都刷新
    updateById(session);
}
```

```java
// ChatServiceImpl:发起对话前调用(记得在启动类加 @EnableAsync)
chatSessionService.update(sessionId, question, userId);
```

> 为什么要异步?**保存标题/时间跟主流程无关**,同步做会拖慢首字响应;异步执行 + 主流程照常。

## 二、查询历史会话(按时间分组)

### 2.1 效果

```
当天:      [...]
最近30天:  [...]
最近1年:   [...]
1年以上:   [...]
```

最多返回 **30 条**。

### 2.2 实现

```java
@Override
public Map<String, List<ChatSessionVO>> queryHistorySession() {
    Long userId = UserContext.getUser();

    // 1. 查该用户的会话(有标题的),按更新时间倒序,最多 30 条
    List<ChatSession> list = lambdaQuery()
            .eq(ChatSession::getUserId, userId)
            .isNotNull(ChatSession::getTitle)
            .orderByDesc(ChatSession::getUpdateTime)
            .last("LIMIT 30")
            .list();
    if (CollUtil.isEmpty(list)) return Map.of();

    List<ChatSessionVO> vos = CollStreamUtil.toList(list, s -> ChatSessionVO.builder()
            .sessionId(s.getSessionId()).title(s.getTitle()).updateTime(s.getUpdateTime()).build());

    // 2. 按更新时间分组(当天/最近30天/最近1年/1年以上)
    var now = LocalDateTime.now().toLocalDate();
    return CollStreamUtil.groupByKey(vos, vo -> {
        long between = Math.abs(ChronoUnit.DAYS.between(vo.getUpdateTime().toLocalDate(), now));
        if (between == 0)        return "当天";
        else if (between <= 30)  return "最近30天";
        else if (between <= 365) return "最近1年";
        else                     return "1年以上";
    });
}
```

> 用 `CollStreamUtil.groupByKey` 一行完成分组;分组 key 直接就是给前端展示的中文标签。

## 三、删除历史会话

要点:**数据库 + Redis 一起删**。

```java
@Override
public void deleteHistorySession(String sessionId) {
    // 1. 删数据库记录(限当前用户,防止删别人的)
    remove(Wrappers.<ChatSession>lambdaQuery()
            .eq(ChatSession::getSessionId, sessionId)
            .eq(ChatSession::getUserId, UserContext.getUser()));

    // 2. 删 Redis 里的会话记忆
    String conversationId = ChatService.getConversationId(sessionId);
    redisChatMemory.clear(conversationId);
}
```

> 💡 只删库不删 Redis → 用户重建同 sessionId 时会"看到幽灵记忆";**双写双删**才干净。

## 四、修改标题(用户手动改)

```java
@Override
public void updateTitle(String sessionId, String title) {
    lambdaUpdate()
            .set(ChatSession::getTitle, StrUtil.sub(title, 0, 100))   // 限长 100
            .eq(ChatSession::getSessionId, sessionId)
            .eq(ChatSession::getUserId, UserContext.getUser())
            .update();
}
```

> **永远带上 `userId` 条件**——多租户/多用户系统的铁律,别让人改到别人的数据。

## 五、进阶:让 AI 提炼标题

目标:像主流 AI 产品那样,把"第一次提问 + AI 回答"丢给模型,生成 ≤18 字的精炼标题。

### 5.1 四个要点

```
1. 输入 = 第一次的用户提问 + AI 的回答
2. 不能用主对话的 ChatClient —— 要新建一个(提示词/参数都不同)
3. 提示词同样放 Nacos(支持热更新)
4. 保存时机:从"对话前"改到"第一次对话后"
```

### 5.2 标题提示词(Nacos:system-chat-title-message.txt)

```
请根据对话内容生成中文标题,严格遵循:
1. 长度 ≤ 18 字符(含标点/空格,1 个汉字 = 1 字符)
2. 直接输出标题,无任何解释或格式
3. 禁用非核心词汇:"问题""帮助""方法"等(除非是对话核心)
4. 关键词前置,突出对话主旨
5. 语言精简,删除冗余修饰词

示例对照:
[对话] 用户问 Python 正则表达式提取邮箱,答 re 模块代码示例
[标题] Python 正则提取邮箱
[对话] 用户报登录闪退,客服让清缓存升级版本
[标题] 登录闪退处理方案
```

### 5.3 调用与时机

```java
@Async
@Override
public void update(String sessionId, String title, Long userId) {
    ChatSession session = lambdaQuery()
            .eq(ChatSession::getSessionId, sessionId)
            .eq(ChatSession::getUserId, userId).one();
    if (session == null) return;

    if (StrUtil.isEmpty(session.getTitle()) && StrUtil.isNotEmpty(title)) {
        // ★ 用独立的 ChatClient + 独立提示词,让 AI 提炼标题
        String titleContent = ChatClient.builder(dashScopeChatModel)
                .build()
                .prompt()
                .system(systemPromptConfig.getChatTitleMessage().get())
                .user(StrUtil.format("对话内容:{}", title))
                .call()
                .content();
        session.setTitle(titleContent);
    }
    session.setUpdateTime(LocalDateTimeUtil.now());
    updateById(session);
}
```

```java
// ChatServiceImpl:改成"流结束后"再更新(doFinally)
```

> 注意:标题提炼会**多一次模型调用**(要算成本);且必须**异步**,否则会拖慢对话。

## 六、本节速记

1. 标题策略:**首次提问存标题 + 每次提问更新时间**,用 `@Async` 异步做;
2. 历史查询:`LIMIT 30` + 按时间差**分组**(当天/30天/1年/更久);
3. 删除会话要**数据库 + Redis 双删**;
4. 所有用户维度的更新/删除,**必须带 userId 条件**;
5. AI 提炼标题:**独立 ChatClient + 独立 Nacos 提示词 + 对话结束后触发**;
6. 异步 + 限长 + 独立提示词,是标题功能的三个工程要点。
