## 一句话速记

1. Tool 查询走**已有微服务(Feign)**,返回对象加 `@JsonPropertyDescription` 让模型和前端都懂;
2. 工具结果回传前端 = **requestId + ToolResultHolder + 流末尾 PARAM(1003)事件**;
3. 预下单要传 **userId**;结构化参数必须**随消息持久化**(否则历史里卡片就没了);
4. RAG 生产用 **ES 向量库**:`dimensions` 与向量模型一致、写入分批(≤3 条);
5. 历史对话:**异步标题 + 时间分组 + 库/缓存双删 + AI 提炼标题**;
6. 贯穿始终的安全习惯:所有查询更新**带 userId**,密钥只走环境变量。
