# 基本对话:新建会话与流式对话(2026-09-12)

> 来源:AI 课程导图(10 基本对话与课程咨询)整理,面向 Java 初级工程师。
> 目标:实现 AI 助手的两个基础能力——**新建会话**(sessionId + 热门问题)和**流式对话**(SSE 逐字输出)。

---

## 一、新建会话

### 1.1 需求

打开 AI 助手时先建一个会话,后端返回:会话 id、助手标题/描述、几个**热门问题示例**(前端展示"换一换")。

### 1.2 三个设计问题(先想清楚再写代码)

| 问题 | 解决思路 |
|------|----------|
| sessionId 怎么生成? | 用 **UUID**:字符串、不重复,`IdUtil.fastSimpleUUID()` |
| 要不要入库? | **要**。以后查历史对话必须按 sessionId 查,所以要落库 |
| 热门问题怎么做? | 写死不好 → 放 **Nacos 配置中心**,随机取 n 个,可随时改 |

### 1.3 接口设计

```
POST /session?n=3

{
  "sessionId": "718f331076e442059a10da26be5f292d",
  "title": "Hi,我是你的 AI 学习助理",
  "describe": "我可以推荐课程、答疑解惑,也能陪你聊点别的~",
  "examples": [
    { "title": "知识讲解", "describe": "面向对象的三大特征是什么?" },
    { "title": "课程介绍", "describe": "《Java 进阶实战》能学到什么?" },
    { "title": "课程购买", "describe": "《Java 进阶实战》多少钱?" }
  ]
}
```

### 1.4 数据库表

```sql
CREATE TABLE `chat_session` (
  `id` BIGINT NOT NULL COMMENT '数据id',
  `session_id` VARCHAR(32) NOT NULL COMMENT '会话id',
  `user_id` BIGINT NOT NULL DEFAULT 0 COMMENT '用户id',
  `title` VARCHAR(100) NULL COMMENT '会话标题',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `creater` BIGINT NOT NULL COMMENT '创建人',
  `updater` BIGINT NOT NULL COMMENT '更新人',
  PRIMARY KEY (`id`),
  INDEX `session_id_index` (`session_id`),
  INDEX `user_id_index` (`user_id`),
  INDEX `update_time_index` (`update_time`)
) COMMENT='对话session';
```

> 设计要点:`session_id` 和 `user_id` 建索引(查询都按它俩);`update_time` 索引(历史列表按时间排序)。

### 1.5 代码骨架(标准三层)

```java
// 实体
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@TableName("chat_session")
public class ChatSession implements Serializable {
    @TableId(type = IdType.ASSIGN_ID)
    private Long id;
    private String sessionId;
    private Long userId;
    private String title;
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private Long creater;
    private Long updater;
}

// Mapper:继承 BaseMapper 即可
@Mapper
public interface ChatSessionMapper extends BaseMapper<ChatSession> { }
```

```java
// 配置类:把 Nacos 里的热门问题映射成对象
@Data
@Configuration
@ConfigurationProperties(prefix = "demo.ai.session")
public class SessionProperties {
    private String title;
    private String describe;
    private List<SessionVO.Example> examples;
}
```

```java
// Service 实现:配置 → VO,随机取热门问题,生成 sessionId 并入库
@Service
@RequiredArgsConstructor
public class ChatSessionServiceImpl extends ServiceImpl<ChatSessionMapper, ChatSession>
        implements ChatSessionService {

    private final SessionProperties sessionProperties;

    @Override
    public SessionVO createSession(Integer num) {
        // 1. 把配置拷贝进 VO
        SessionVO vo = BeanUtil.toBean(sessionProperties, SessionVO.class);
        // 2. 随机挑 num 个热门问题
        vo.setExamples(RandomUtil.randomEleList(sessionProperties.getExamples(), num));
        // 3. 生成 sessionId
        vo.setSessionId(IdUtil.fastSimpleUUID());
        // 4. 落库(userId 从登录上下文里取)
        save(ChatSession.builder()
                .sessionId(vo.getSessionId())
                .userId(UserContext.getUser())
                .build());
        return vo;
    }
}
```

```java
@RestController
@RequestMapping("/session")
@RequiredArgsConstructor
public class SessionController {
    private final ChatSessionService chatSessionService;

    @PostMapping
    public SessionVO createSession(@RequestParam(value = "n", defaultValue = "3") Integer num) {
        return chatSessionService.createSession(num);
    }

    /** 热门问题(换一换) */
    @GetMapping("/hot")
    public List<SessionVO.Example> hotExamples(@RequestParam(value = "n", defaultValue = "3") Integer num) {
        return chatSessionService.hotExamples(num);
    }
}
```

> 小技巧:**配置 → VO 用 `BeanUtil.toBean`,`随机取 n 个` 用 `RandomUtil.randomEleList`**——两行搞定,不用手写循环。

## 二、流式对话(SSE)

### 2.1 为什么要流式

大模型生成慢,等全部生成完再返回,用户要盯空白屏十几秒。**流式 = 生成一点推一点**,体验像打字机。

### 2.2 接口与数据格式

```
POST /chat
{ "question": "能帮我推荐一个合适的课吗?", "sessionId": "f1dbf6ca..." }

响应(SSE,每行一个 JSON):
data:{"eventData":"课程","eventType":1001}
data:{"eventData":" id","eventType":1001}
data:{"eventType":1002}
```

| eventType | 含义 |
|-----------|------|
| **1001** | 数据事件(一段文本) |
| **1002** | 停止事件(本次回答结束) |
| **1003** | 参数事件(结构化数据,如课程卡片,后面课程查询会用到) |

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class ChatEventVO {
    private Object eventData;   // 文本内容或结构化数据
    private int eventType;      // 1001/1002/1003
}

@Getter
public enum ChatEventTypeEnum {
    DATA(1001, "数据事件"),
    STOP(1002, "停止事件"),
    PARAM(1003, "参数事件");
    private final int value;
    private final String desc;
    ChatEventTypeEnum(int value, String desc) { this.value = value; this.desc = desc; }
}
```

### 2.3 ChatClient 配置

```java
@Configuration
public class SpringAIConfig {
    @Bean
    public ChatClient chatClient(DashScopeChatModel dashScopeChatModel) {
        return ChatClient.builder(dashScopeChatModel)
                .defaultAdvisors(SimpleLoggerAdvisor.builder().build())   // 先加日志,方便调试
                .build();
    }
}
```

### 2.4 Service:把流"翻译"成事件流

```java
@Override
public Flux<ChatEventVO> chat(String question, String sessionId) {
    return chatClient.prompt()
            .user(question)
            .stream()
            .chatResponse()
            .map(chatResponse -> ChatEventVO.builder()
                    .eventData(chatResponse.getResult().getOutput().getText())   // 取出这段文本
                    .eventType(ChatEventTypeEnum.DATA.getValue())
                    .build())
            .concatWith(Flux.just(                                              // 结尾追加"停止事件"
                    ChatEventVO.builder().eventType(ChatEventTypeEnum.STOP.getValue()).build()));
}
```

### 2.5 Controller:声明 `text/event-stream`

```java
@NoWrapper      // 项目自定义注解:标注该接口返回值不做统一包装(否则 SSE 会被包成 JSON 对象)
@PostMapping(produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<ChatEventVO> chat(@RequestBody ChatDTO chatDTO) {
    return chatService.chat(chatDTO.getQuestion(), chatDTO.getSessionId());
}
```

> 💡 两个易错点:
> ① 返回值必须是 `Flux` + `produces = TEXT_EVENT_STREAM_VALUE`,否则不是流式;
> ② 项目若有"统一响应包装",SSE 接口要**排除包装**(自定义注解 / 路径白名单)。

### 2.6 常见错误码(调试对照)

| 现象 | 原因 |
|------|------|
| 401 | 没登录 / token 没配到全局变量里 |
| 403 | 模型无权限,换个模型再试 |
| 400 | 账号欠费或参数问题 |

## 三、本节速记

1. 新建会话:UUID 生成 sessionId、**必须落库**(历史查询要用)、热门问题放**配置中心**随机取;
2. 流式对话:`Flux` + `produces=text/event-stream`,SSE 每行一个 JSON 事件;
3. 事件协议:**1001 数据、1002 停止、1003 参数**(结构化数据);
4. SSE 接口要**排除统一响应包装**,否则前端解不出来;
5. 登录类 401 多半是没带 token,先查全局请求头。
