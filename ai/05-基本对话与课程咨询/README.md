## 一句话速记

1. 加 AI = 新建 AI 微服务 + SpringAI BOM + 平台 starter + Nacos 配置 + 网关路由;
2. 新建会话:UUID + 落库 + 热门问题配置化;流式对话:`Flux` + `text/event-stream`;
3. 事件协议:**1001 数据 / 1002 停止 / 1003 参数**;
4. 停止生成 = 标记 + `takeWhile`;提示词放 Nacos 热更新;
5. 会话记忆自实现 Redis 仓库;`Message` 不能直接序列化 → 自定义镜像类;
6. 中断路径要兜底:**`doOnCancel` 手动补存,且必须写在 `takeWhile` 之前**。
