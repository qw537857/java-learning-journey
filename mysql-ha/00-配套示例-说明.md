# mysql-ha 配套示例

> 面试角度 + 贯穿商城案例的讲解见三篇主笔记。
> 这里给**最小可运行**的验证示例思路(包名统一 `com.example`,连接占位符)。
> 目的是让你"看得懂、本地能跑通、面试能讲",不做重工程。

## 1. 读写分离:应用层 AOP 路由(最直观)

不引框架,自己写一个简单路由,先理解原理:

```java
package com.example.datasource;

import javax.sql.DataSource;
import org.springframework.jdbc.datasource.lookup.AbstractRoutingDataSource;

/** 根据当前线程标记选择主/从数据源 */
public class RoutingDataSource extends AbstractRoutingDataSource {

    // ThreadLocal 标记本次请求走主还是从
    private static final ThreadLocal<Boolean> USE_MASTER = new ThreadLocal<>();

    public static void useMaster(boolean master) { USE_MASTER.set(master); }

    @Override
    protected Object determineCurrentLookupKey() {
        Boolean master = USE_MASTER.get();
        USE_MASTER.remove();
        return Boolean.TRUE.equals(master) ? "master" : "slave";
    }
}
```

配合一个切面:方法打 `@Transactional` 或自定义 `@ReadOnly` 注解时切换路由。核心就一句话:**查走从、写走主,事务内全程走主**。

## 2. 分库分表:ShardingSphere-JDBC + SpringBoot

**要点**(不是完整工程,是启动路径):

1. SpringBoot 引入 `shardingsphere-jdbc-spring-boot-starter`。
2. `application.yml` 配置参考主笔记 `04`(数据源 + 读写分离 + 分表规则)。
3. **提前建好物理表**:`t_order_0 ~ t_order_15`(建表 SQL 自己按 order 结构写)。
4. 代码里写 `t_order`(逻辑表名),ShardingSphere 自动路由到对应分片表。
5. 主键不要用自增,配**雪花算法生成分布式 ID**。

```java
package com.example.order.service;

import com.example.order.entity.TOrder;
import com.example.order.mapper.TOrderMapper;
import org.springframework.stereotype.Service;
import javax.annotation.Resource;

@Service
public class OrderService {

    @Resource
    private TOrderMapper orderMapper;

    /** 新增订单:按 user_id 分片,落到 t_order_x */
    public void create(TOrder order) {
        // id 用雪花等分布式 ID 生成,不能自增
        orderMapper.insert(order);
    }

    /** 查某用户的订单:一个用户在一个分片,一次查询只打一片 */
    public java.util.List<TOrder> listByUser(Long userId) {
        return orderMapper.selectByUserId(userId);
    }
}
```

> ⚠️ **面试讲解时强调**:上面 MyBatis-Plus / Mapper 语法按你项目实际为准,这里重点是"**逻辑表 t_order + user_id 分片 + 分布式主键**"三个概念。

## 3. 本地最小验证三步

1. 起一台 MySQL,开 binlog,建 `order_db`,再按 16 片建 `t_order_0..15`。
2. 配 ShardingSphere 数据源和分表规则(yaml 见主笔记 `03`)。
3. 起 SpringBoot 插入几条不同 `user_id` 的数据,观察落到了不同 `t_order_x` 表。

跑通这三个概念(逻辑表/分片键/分布式 ID),面试这块就已经能讲出实证了。
