## 贯穿案例:商城订单系统

整套笔记围绕同一个系统演进,方便理解每个概念"到底解决什么问题":

| 阶段 | 数据量级 | 痛点 | 引入方案 |
|------|---------|------|---------|
| 单机起步 | 万级 | 数据都在一台库,挂了全挂 | 主从复制 + 读写分离 |
| 业务增长 | 百万级 | 读多写少,主库扛不住读 | 一主多从 + 读写分离落地 |
| 高并发 | 千万级 | 单表数据量大、索引退化 | 分库分表 + 集群/中间件 |
| 追求稳定 | 任何阶段 | 主库宕机要自动切换 | Keepalived / Orchestrator / MGR |
| 灾难恢复 | 任何阶段 | 误删/机房事故要能找回 | 全量+增量备份、跨机房容灾 |
